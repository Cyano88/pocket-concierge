# Pre-hackathon baseline

Snapshot date: 2026-07-25

This baseline contains the OKX-only Pocket Concierge workflow:

- deterministic mission and cycle planning;
- immutable manifest approval;
- buyer-side Pocket Bills execution instructions;
- explicit confirmation and maximum-price requirements;
- private customer data kept in the local buyer;
- allowlisted, token-scoped delivery verification;
- idempotent external and downstream order identifiers;
- terminal `delivered` and `needs_review` states.

It does not contain a Prava shopping action, Prava authentication, merchant search, quotes, payment sessions, passkey approval, checkout, or subscription purchasing.

The new hackathon workflow will be developed separately during the Agentic Commerce Hackathon window and disclosed as new work. Prava will remain a distinct merchant-commerce rail and will not be used for crypto, wallet funding, transfers, wagering, payroll, or Nigerian bill vending.
